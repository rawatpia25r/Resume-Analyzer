## 📌 Overview

Resume Analyzer is an AI-powered web application that helps job seekers evaluate how well their resume matches a specific job description.

Simply upload your resume, paste the job description, and receive detailed insights including:

* 📊 Resume Match Score
* 🎯 ATS Compatibility Analysis
* 🛠 Missing Skills Detection
* 💡 Improvement Suggestions
* 📄 Resume Quality Feedback

The goal is to help candidates optimize their resumes before applying for jobs.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/rawatpia25r/Resume-Analyzer.git
```

Move into the project

```bash
cd Resume-Analyzer
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

If your project has separate frontend/backend folders:

```bash
cd client
npm install

cd ../server
npm install
```

---

# 🔑 Environment Variables

Create a `.env` file inside the server directory.

Example:

```env
GEMINI_API_KEY=your_api_key
PORT=5000
```

> Replace the values with your own credentials.

# 🚀 How It Works

1. Upload your resume.
2. Paste the target job description.
3. The application extracts resume content.
4. AI compares your resume with the job description.
5. A detailed report is generated showing:

   * ATS Score
   * Matching Percentage
   * Missing Skills
   * Resume Strengths
   * Improvement Suggestions
